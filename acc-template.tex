% Makros für Inhalte
\newcommand{\systemname}{Ihr System}
\newcommand{\teamname}{Ihr Team}
\newcommand{\workshopdate}{\today}
\newcommand{\iteration}{v1.0}

\newcommand{\valuepropositioncontent}{
Was ist der Kern des Business Case oder der ökonomische Treiber hinter dem System?
}

\newcommand{\keystakeholdercontent}{
Für wen schaffen wir Wert? Wer sind die Kunden? Wer bezahlt? Wer trägt bei?
}

\newcommand{\corefunctionscontent}{
Die wichtigsten Funktionen, Features oder Use Cases. Welche Aktivitäten oder Prozesse werden unterstützt?
}

\newcommand{\qualityrequirementscontent}{
Geschwindigkeit, Skalierbarkeit, Zuverlässigkeit, Benutzerfreundlichkeit, Sicherheit, Kapazität, Flexibilität oder ähnliches.
}

\newcommand{\businesscontextcontent}{
Wichtige externe Schnittstellen oder benachbarte Systeme, einschließlich wichtiger Akteure oder Benutzerrollen.

\vspace{5mm}

Platz für Diagramm oder weitere Kontextinformationen.
}

\newcommand{\componentsmodulescontent}{
Hauptbausteine des Systems: wichtige Subsysteme, Module, Services.
}

\newcommand{\coredecisionscontent}{
Welche Entscheidungen haben zum aktuellen Zustand geführt? Auf welche sind Sie besonders stolz? Welche haben sich als fragwürdig oder schmerzhaft erwiesen?
}

\newcommand{\technologiescontent}{
Die wichtigsten verwendeten Technologien für Entwicklung und Betrieb: Programmiersprachen, Frameworks, Datenbanken, Cloud-Provider, etc.
}

\newcommand{\risksmissinginfocontent}{
Bekannte Probleme und Risiken? Welche Informationen fehlen oder sind verloren gegangen? Was hindert das Team daran, schneller besseren Wert zu liefern?
}
